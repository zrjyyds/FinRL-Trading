# 术语表

买入（Buy）
零基础解释：用现金买入资产。

卖出（Sell）
零基础解释：卖掉已有资产换回现金。

做多（Long）
零基础解释：认为资产会上涨，因此买入并持有。

做空（Short）
零基础解释：认为资产会下跌，通过借入卖出再低价买回获利，但亏损可能很大。

开仓（Open Position）
零基础解释：新建立一笔持仓。

平仓（Close Position）
零基础解释：结束已有持仓。

持仓（Position）
零基础解释：账户当前持有的资产数量和价值。

现金（Cash）
零基础解释：没有投入资产、留在账户中的资金。

收益率（Return）
零基础解释：收益或亏损占本金的比例。

简单收益率（Simple Return）
零基础解释：用 `今天价格 / 昨天价格 - 1` 计算的收益率。

对数收益率（Log Return）
零基础解释：用价格比值的自然对数计算的收益率，便于做连续累计。

累计收益率（Cumulative Return）
零基础解释：从开始到现在总共涨跌了多少。

年化收益率（Annualized Return）
零基础解释：把一段时间的收益换算成一年大约是多少。

波动率（Volatility）
零基础解释：收益上下波动的剧烈程度。

年化波动率（Annualized Volatility）
零基础解释：把日收益波动换算成一年的波动程度。

最大回撤（Maximum Drawdown，MDD）
零基础解释：资金从某个历史最高点跌到之后最低点的最大跌幅。

夏普比率（Sharpe Ratio）
零基础解释：衡量每承担一单位波动风险，获得了多少超额收益。

因子（Factor）
零基础解释：用于解释或预测收益的变量。

动量因子（Momentum Factor）
零基础解释：用过去一段时间涨跌幅衡量资产强弱的因子。

情绪因子（Sentiment Factor）
零基础解释：把新闻情绪转成数字后形成的因子。

回测（Backtesting）
零基础解释：用历史数据模拟策略过去会怎样表现。

基准（Benchmark）
零基础解释：用来比较策略表现的参照对象。

调仓（Rebalance）
零基础解释：按新的目标权重调整持仓。

交易费用（Transaction Cost）
零基础解释：买卖资产时产生的手续费或成本。

滑点（Slippage）
零基础解释：理论成交价和实际成交价之间的差异。

换手率（Turnover）
零基础解释：调仓时买卖金额占组合价值的比例。

未来数据泄漏（Look-Ahead Bias）
零基础解释：历史回测时使用了当时还不知道的信息。

幸存者偏差（Survivorship Bias）
零基础解释：只看现在还存在的资产，忽略过去消失的资产。

过拟合（Overfitting）
零基础解释：模型太贴合历史样本，未来可能表现不好。

人工智能（Artificial Intelligence，AI）
零基础解释：让机器表现出类似智能行为的技术总称。

机器学习（Machine Learning，ML）
零基础解释：让程序从数据中学习规律的方法。

深度学习（Deep Learning，DL）
零基础解释：使用多层神经网络进行学习的方法。

大语言模型（Large Language Model，LLM）
零基础解释：能够处理和生成自然语言文本的大型模型。

令牌（Token）
零基础解释：模型处理文本时使用的基本单位。

提示词（Prompt）
零基础解释：写给模型的任务说明。

系统消息（System Message）
零基础解释：给模型设定角色和规则的消息。

用户消息（User Message）
零基础解释：用户向模型提出任务的消息。

助手消息（Assistant Message）
零基础解释：模型给出的回答消息。

上下文窗口（Context Window）
零基础解释：模型一次能看到的最大文本范围。

温度（Temperature）
零基础解释：控制模型回答随机性的参数。

结构化输出（Structured Output）
零基础解释：让模型按固定字段返回结果，方便程序读取。

JavaScript 对象表示法（JavaScript Object Notation，JSON）
零基础解释：常用的数据交换格式，像带字段名的字典。

JSON 模式（JSON Schema）
零基础解释：用来检查 JSON 字段和类型是否符合规则。

幻觉（Hallucination）
零基础解释：模型生成看起来合理但不真实的内容。

提示词注入（Prompt Injection）
零基础解释：外部文本试图操纵模型偏离原任务。

嵌入向量（Embedding）
零基础解释：把文本转换成数字向量，便于计算相似度。

检索（Retrieval）
零基础解释：从资料库中找出和问题最相关的内容。

检索增强生成（Retrieval-Augmented Generation，RAG）
零基础解释：先检索资料，再把资料交给模型生成回答。

大语言模型提供商（LLM Provider）
零基础解释：提供模型调用能力的服务或本地组件。

模拟提供商（Mock Provider）
零基础解释：不联网、不收费、按规则返回结果的假模型。

模型推理（Model Inference）
零基础解释：把输入交给模型并得到输出的过程。

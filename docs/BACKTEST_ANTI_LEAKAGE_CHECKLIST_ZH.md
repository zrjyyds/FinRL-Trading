# 回测与数据泄漏防护清单

本清单用于后续所有因子、机器学习和组合回测实验。任何正式结果进入作品集前，都必须逐项检查。

## 1. 总原则

- 只能使用当时已经可见的数据。
- 训练、验证、测试必须按时间切分。
- 测试集只允许最终评估，不允许反复调参。
- 成交必须晚于信号生成。
- 回测必须纳入交易成本和无法成交情形。
- 所有结果必须可离线复现。

## 2. 数据时间戳检查

| 检查项 | 必须满足 | 当前项目风险 |
|---|---|---|
| 行情日期 | 价格、成交量、复权因子与 `trade_date` 对齐 | 现有美股数据可用，但 A 股 schema 缺失 |
| 财报日期 | 财务字段按 `announce_date` 后的可交易日生效 | 现有 DB 有 `filing_date`、`accepted_date`，但 A 股披露语义未建立 |
| 新闻日期 | 新闻只能在发布时间之后使用 | 新闻情绪目前不是主线，未来若使用必须严格对齐 |
| 股票池日期 | 股票池只使用当日已生效成分 | S&P500 有 PIT 思路，A 股缺失 |
| 交易状态日期 | 停牌、涨跌停、ST 状态与交易日对齐 | 当前 A 股交易状态缺失 |

## 3. 未来函数检查

必须回答：

- 因子计算是否使用了未来价格？
- 财务因子是否使用了尚未公告的报表？
- 复权价格是否引入未来分红拆股信息，并影响了交易价格？
- 去极值边界是否使用了测试期数据？
- 标准化均值和方差是否使用了测试期数据？
- 缺失值填充值是否使用了验证/测试期统计量？
- 特征选择是否看过测试集表现？
- 标签是否被提前合并进特征处理？

当前发现的重点风险：

- `src/data/data_processor.py` 中 `future_return` 与 `merge_asof` 需要单测证明标签窗口晚于特征窗口。
- `src/strategies/ml_bucket_selection.py` 中全局 winsorize/中位数填充存在分布信息泄漏风险。
- `--ref-date/--end-date` 下载实际收益的历史评估路径若用于调参，会让测试集被反复使用。

## 4. 时间序列切分检查

禁止：

- 对时间序列样本使用随机切分作为正式样本外结果。
- 在同一股票不同日期之间 shuffle 后报告测试收益。
- 用未来日期的横截面统计量处理过去样本。

允许：

- 固定时间切分：train -> valid -> test。
- 滚动训练：过去窗口训练，未来窗口预测。
- expanding window：从起始日扩展训练，预测未来。

验收断言：

```text
max(train_date) < min(valid_date)
max(valid_date) < min(test_date)
```

滚动训练断言：

```text
max(fit_window_date) < min(prediction_date)
```

## 5. 股票池泄漏检查

必须满足：

- 每个调仓日只使用当日属于股票池且可交易的股票。
- 退市股票不能从历史样本中消失。
- 新上市股票必须满足上市天数限制。
- ST、停牌、涨跌停规则在回测前确定，不能事后筛选亏损样本。

当前项目状态：

- S&P500 历史成分可作为 point-in-time 股票池参考。
- 尚未具备 A 股历史股票池和交易状态主线。

## 6. 财务数据披露日期检查

财务字段必须满足：

```text
report_period <= announce_date <= effective_trade_date <= factor_date
```

禁止：

- 用报告期日期直接代表可用日期。
- 用年报/季报的最终修订值回填历史。
- 对没有披露日期的财务数据进行正式回测。

若缺少 `announce_date`：

- 该字段只能用于演示，不得用于正式绩效。
- 或按保守滞后规则处理，并在报告中标记风险。

## 7. 停牌、涨跌停和成交检查

A 股回测必须考虑：

- 停牌不可买入、不可卖出。
- 涨停通常不可买入或成交受限。
- 跌停通常不可卖出或成交受限。
- 成交额过小的股票需要流动性过滤。
- T+1 规则影响卖出。

当前项目风险：

- 现有 `bt` 回测主要是目标权重再平衡。
- 未发现 A 股停牌、涨跌停、T+1 主线成交模拟。

## 8. 交易成本检查

至少包含：

- 买入佣金。
- 卖出佣金。
- 卖出印花税。
- 过户费，如适用。
- 滑点或冲击成本。
- 最低佣金，如适用。

验收断言：

```text
net_return <= gross_return
turnover == 0 时 cost == 0
cost 随 turnover 增加而不下降
```

当前项目状态：

- 已有 flat transaction cost 和 bt CostModel 入口。
- 缺 A 股成本细节和无法成交逻辑。

## 9. 标签与特征错位检查

每一行训练样本必须满足：

```text
feature_available_time <= signal_time < execution_time < label_end_time
```

常见错误：

- 用 `t` 日收盘后计算的因子，在 `t` 日收盘价成交。
- 用 `t+1` 的成交状态决定 `t` 日是否入池。
- 用未来收益不为空来筛选样本，导致幸存者偏差。
- 用未来价格计算当前因子的缺失填充值。

## 10. 训练、验证、测试隔离

必须隔离：

- 数据清洗参数。
- winsorize 边界。
- imputer 填充值。
- scaler 均值/方差。
- 特征选择。
- 模型参数选择。
- 组合阈值和 top-N。

正式报告中应记录：

- train 日期范围。
- valid 日期范围。
- test 日期范围。
- 是否滚动训练。
- 每个窗口的样本量。
- 每次实验的随机种子。

## 11. 结果复现检查

每次正式实验必须输出：

- 配置文件。
- 数据版本或文件 hash。
- git commit。
- 运行时间。
- 随机种子。
- 依赖版本。
- summary CSV。
- 图表路径。
- 研究报告路径。

## 12. 本轮审计结论

本轮发现数据泄漏或回测风险：是。

风险不是证明当前所有结果无效，而是说明当前代码库尚未具备面向 A 股量化研究作品集的严格验证闭环。后续 Phase 必须先补防泄漏数据层和测试，再报告策略收益。

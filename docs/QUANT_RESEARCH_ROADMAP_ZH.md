# 量化研究作品集路线图

本路线图将项目主线调整为：A 股中低频多因子选股 + XGBoost/LightGBM + 严格样本外回测 + 组合构建 + 模型归因。

强化学习、FinRL、Alpaca 交易和在线数据抓取保留为扩展路线，不删除原代码，但不作为当前主线推进。

## Phase QR-0：项目扫描、差距分析和风险审计

| 项目 | 内容 |
|---|---|
| 学习目标 | 理解现有项目边界，识别可复用模块、岗位差距和回测风险 |
| 实现任务 | 扫描 `src/`、`data/`、`docs/`、`examples/`、`figs/`、requirements、配置和已有结果；形成能力矩阵、差距分析、路线图、因子规范、防泄漏清单和作品集蓝图 |
| 输入与输出 | 输入为当前代码库；输出为 6 份中文规划文档 |
| 自动测试 | 不运行训练；仅做 `git diff --check` 和变更范围检查 |
| 验收指标 | 只修改目标文档；明确能力状态；明确风险；明确下一 Phase |
| 失败处理 | 若发现核心代码被误改，立即停止并回滚本轮文档外改动 |
| 是否允许进入下一 Phase | 允许，但仅在文档完成且核心代码未修改后进入 QR-1 |

## Phase QR-1：A 股离线研究数据层与防泄漏基线

| 项目 | 内容 |
|---|---|
| 学习目标 | 建立可信的 point-in-time 数据层，理解交易日、股票池、复权、披露日期和标签时间对齐 |
| 实现任务 | 新增离线小样本 A 股数据 schema；定义 `calendar`、`universe`、`prices`、`factors_raw`、`financials`、`tradability`；实现只读加载器；构造小型 fixtures；建立防泄漏断言 |
| 输入与输出 | 输入为离线 CSV/Parquet fixtures；输出为标准 DataFrame 和数据质量报告 |
| 自动测试 | schema 校验、日期单调性、股票池 PIT 校验、财报披露后生效、标签窗口晚于特征窗口、无随机时间切分 |
| 验收指标 | 所有测试离线通过；任一特征行可追溯到当时已知数据；无联网、无训练、无交易 |
| 失败处理 | 若数据字段不足，降级为更小 fixtures；若披露日期缺失，禁止使用该财务字段 |
| 是否允许进入下一 Phase | 只有数据层测试全通过，才允许进入 QR-2 |

## Phase QR-2：因子计算、清洗和中性化

| 项目 | 内容 |
|---|---|
| 学习目标 | 掌握价值、质量、动量、波动、流动性等中低频因子的标准处理流程 |
| 实现任务 | 实现因子长表；按日期去极值；按日期标准化；行业中性化；市值中性化；保存 factor metadata |
| 输入与输出 | 输入为 QR-1 标准数据；输出为 `factor_date/ticker/factor_id/value` 因子表和处理日志 |
| 自动测试 | 去极值只用当期截面或训练窗口；标准化后均值/方差符合预期；中性化后与行业/市值暴露显著下降 |
| 验收指标 | 至少 10 个基础因子；每个因子有定义、方向、频率、缺失处理和时间戳说明 |
| 失败处理 | 若行业或市值字段缺失，先跳过对应中性化并在报告中标记不可用 |
| 是否允许进入下一 Phase | 因子表可复现且防泄漏测试通过后允许进入 QR-3 |

## Phase QR-3：IC、RankIC 和分组回测

| 项目 | 内容 |
|---|---|
| 学习目标 | 学会用横截面相关性和分组收益评价因子有效性 |
| 实现任务 | 实现 Pearson IC、Spearman RankIC、ICIR、t 值、分位数组合收益、多空收益、换手率、覆盖率 |
| 输入与输出 | 输入为 QR-2 因子表和未来收益标签；输出为因子评价表、分组回测曲线和图表 |
| 自动测试 | 人工小样本 IC 可手算对齐；分组排序方向正确；标签窗口严格晚于因子日期 |
| 验收指标 | 每个因子输出月度 IC、RankIC、分组收益和稳定性统计；报告可解释保留/剔除因子 |
| 失败处理 | 若单因子不稳定，不调参硬凑收益；记录失败并进入因子诊断 |
| 是否允许进入下一 Phase | 至少形成一个可解释的因子池后允许进入 QR-4 |

## Phase QR-4：XGBoost/LightGBM 严格样本外建模

| 项目 | 内容 |
|---|---|
| 学习目标 | 掌握中低频横截面机器学习选股、时间序列切分和模型归因 |
| 实现任务 | 实现 train/valid/test 时间切分；滚动训练；XGBoost baseline；LightGBM baseline；参数配置；feature importance；SHAP 或替代归因 |
| 输入与输出 | 输入为 QR-2 因子矩阵和 QR-3 标签；输出为 OOS 预测分数、模型指标、归因表 |
| 自动测试 | 禁止 `train_test_split(shuffle=True)`；scaler/imputer/winsorizer 只 fit 训练窗口；验证集与测试集日期不重叠 |
| 验收指标 | 至少两个模型在同一 OOS 协议下比较；报告包含失败模型和过拟合诊断 |
| 失败处理 | 若树模型过拟合，回退到 Ridge/线性模型作为 baseline；不得用测试集反复调参 |
| 是否允许进入下一 Phase | 只有预测文件和 OOS 协议可复现后允许进入 QR-5 |

## Phase QR-5：组合构建、交易成本和样本外回测

| 项目 | 内容 |
|---|---|
| 学习目标 | 将因子或模型分数转化为可交易组合，并理解成本与约束对收益的影响 |
| 实现任务 | 实现等权 top-N、分数加权、行业约束、市值约束、单票权重上限、换手约束、交易成本、停牌和涨跌停处理 |
| 输入与输出 | 输入为 OOS 预测分数、价格、可交易状态；输出为目标权重、成交模拟、净值曲线、绩效指标 |
| 自动测试 | 权重和为 1；单票/行业/换手约束生效；停牌和涨跌停不可成交；成本扣减方向正确 |
| 验收指标 | 输出年化收益、波动、夏普、最大回撤、换手、成本、超额收益；所有指标基于样本外 |
| 失败处理 | 若无法建模涨跌停或停牌，必须在报告中单独列为回测偏乐观风险 |
| 是否允许进入下一 Phase | 组合回测与成本测试通过后允许进入 QR-6 |

## Phase QR-6：绩效归因、模型归因和研究报告

| 项目 | 内容 |
|---|---|
| 学习目标 | 把研究结果转化为可面试展示的作品集报告 |
| 实现任务 | 实现收益归因、行业归因、因子归因、个股贡献、成本归因；生成 Markdown/HTML 报告和关键图表 |
| 输入与输出 | 输入为 QR-3 到 QR-5 结果；输出为研究报告、图表、实验摘要和 README 展示段落 |
| 自动测试 | 报告引用的文件存在；指标与 summary CSV 一致；图表可重新生成 |
| 验收指标 | 一键离线生成完整报告；报告能解释策略收益来源、失败案例和风险限制 |
| 失败处理 | 若归因不足，先输出可解释的 top contributors 和行业暴露，推迟复杂归因 |
| 是否允许进入下一 Phase | 完成后可作为第一版作品集发布 |

## Phase QR-X：强化学习扩展路线

| 项目 | 内容 |
|---|---|
| 学习目标 | 在主线作品集成熟后，探索 RL/DRL 在组合权重调整中的扩展价值 |
| 实现任务 | 保留 FinRL/DRL 代码，后续只在离线、无交易、安全环境中对比传统组合方法 |
| 输入与输出 | 输入为已验证的离线数据；输出为扩展实验报告 |
| 自动测试 | 禁止联网、禁止下单、限制训练规模、记录随机种子 |
| 验收指标 | RL 结果必须与简单 baseline 比较，不能只展示收益图 |
| 失败处理 | 若训练不稳定或不可复现，标记为负结果 |
| 是否允许进入下一 Phase | 不阻塞主线；仅作为作品集附录 |

## 下一步推荐

当前推荐进入 `Phase QR-1：A 股离线研究数据层与防泄漏基线`。

QR-1 的原则是小而严：先用小样本数据把时间语义、股票池、复权、财报披露、停牌涨跌停和标签窗口做对，再扩展数据规模和模型复杂度。
